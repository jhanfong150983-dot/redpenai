## 目標模型
- 答案卷（含已存）**可直接改**答案/題型/配分（不再強制「重新解析→新版本」）。
- 內容有 diff → 批改頁顯示「**答案卷內容已變更，請重新批改**」＋**解鎖智慧批改**（老師自己決定何時重批）。
- **重批前舊批改全保留**。
- 觸發「已變更」：① 改答案/題型（有 diff）② 換成別的答案卷。**配分不觸發**（純 code 自動重算）。

- 改分一律先寫 `_aiOriginal` 快照。
